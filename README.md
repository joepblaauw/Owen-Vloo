# Vloo Schilderwerken & Onderhoud

Een responsive website in gewone HTML, CSS en JavaScript.
Inclusief een aparte projectpagina met drie voor/na-paren en drie losse resultaatfoto's.

## Openen in Visual Studio Code

1. Pak `vloo-website.zip` uit.
2. Open de map `vloo-website` in Visual Studio Code.
3. Open `index.html` direct in de browser, of installeer de extensie **Live Server** en klik rechtsonder op **Go Live**.

## Eerst aanpassen

- De contactgegevens en het KvK-nummer staan in `index.html`. Controleer ze samen met Owen voor publicatie.
- `projecten.html` toont de nieuwe foto's. Klik op een foto om het originele JPEG-bestand op volledige resolutie in een nieuw tabblad te openen.
- Het offerteformulier maakt een e-mailconcept in het e-mailprogramma van de bezoeker; er wordt niets automatisch verzonden. Voor een rechtstreeks webformulier is later een formulierdienst of backend nodig.
- Teksten staan in `index.html`.
- Kleuren, lettergroottes en indeling staan in `css/style.css`.
- Menu, animaties en formuliermelding staan in `js/script.js`.
- Foto's staan in de map `images`.
